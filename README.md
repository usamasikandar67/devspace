# Professional Portfolio - Muhammad Usama Sikandar

A premium, fully responsive professional portfolio website designed for an AI/ML Engineer. Built with a focus on modern aesthetics, high performance, and seamless user experience.

## 🚀 Live Demo
[usama-sikandar.vercel.app](https://usama-sikandar.vercel.app)

## ✨ Features
- **Modern UI/UX**: Premium dark theme with glassmorphism effects and fluid animations.
- **Fully Responsive**: Optimized for all devices, including specific enhancements for iOS Safari.
- **Interactive Navigation**: Dynamic navigation bar that auto-collapses on mobile for better accessibility.
- **Contact Integration**: Fully functional contact form powered by Formspree API (No backend required).
- **Project Showcases**: Dedicated sections for expertise, journey, and professional works.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (jQuery)
- **Styling**: Bootstrap 4/5, Custom CSS
- **Icons**: FontAwesome, Icomoon
- **Deployment**: Vercel
- **Form Handling**: Formspree REST API

## 📦 Installation & Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/usamasikandar67/devspace.git
   ```
2. Navigate to the project directory:
   ```bash
   cd usama_port
   ```
3. Open `index.html` in your browser or use a live server extension.

## 🚀 Deployment
To deploy your own version to Vercel:
```bash
npx vercel --prod --yes
```
